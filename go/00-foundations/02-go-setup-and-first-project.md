# Go Setup & First Go Project

This note covers the basic Go development setup, the Go toolchain, creating our first Go project, and understanding our first Go program line by line.

---

# 1. Go Extension in Cursor

For Go development in Cursor, install the **Go extension**.

The extension provides useful development features such as:

- Syntax highlighting
- Code completion
- Error detection
- Formatting
- Navigation
- Debugging support
- Integration with `gopls`

The extension makes Cursor understand Go code properly.
